## Matching binaries to source

A desktop build corresponds to the ArchCompose commit it was built from. That commit pins
every Rust dependency in `src-tauri/Cargo.lock` (PhotoCraft by Git revision) and every npm
dependency in `package-lock.json`, so the complete corresponding source is that ArchCompose
commit plus the locked dependency sources. The running app reports the PhotoCraft revision in
"About and licenses".

## Updating

When a dependency changes, run `node scripts/third-party-licenses.mjs` (CI checks it). When
the PhotoCraft revision changes, re-audit the table above against PhotoCraft's `NOTICE` and
`ATTRIBUTION.md` at the new revision and update `docs/UPSTREAM.md`.
